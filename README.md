# discordBotAddTask
Add tasks to google docks  via discord bot

## Example .env file:
- DISCORD_TOKEN = 
- GOOGLE_CREDENTIALS = "credentials.json"
- GOOGLE_TABLE_ID = "<ID from URL>"

## Example access.conf file (just dicord id):
- 123456789012345678
- 098765432109876543

## Get discord id
1. Enable Developer Mode in Discord:
        Settings → Advanced → Developer Mode
2. Account -> ... → "Copy ID"
